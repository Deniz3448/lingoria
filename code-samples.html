Lingoria iOS uygulamasından seçilmiş Swift kaynak dosyaları Curated Swift source files from the Lingoria iOS app

Lingoria, App Store yayınına TestFlight aşamasıyla hazırlanan, AI destekli bir İngilizce öğrenme iOS uygulamasıdır. Tam kaynak kodu özeldir — abonelik mantığını, Apple sunucu bildirim doğrulamasını, ders içeriklerini ve AI komut grafiklerini korur. Bu sayfa, üretim kod tabanının kalitesini değerlendirebilmen için seçilmiş, anonim örnekleri ayrı bir public repo'da bir araya getirir. Lingoria is an AI-powered English-learning iOS app, currently in TestFlight ahead of App Store launch. The full source is private — it protects subscription logic, Apple server notification verification, lesson content and AI prompt graphs. This page collects representative, anonymized excerpts in a separate public repo so reviewers can evaluate the production codebase quality.

İçerik What's inside

Persistence — Kalıcılık Persistence

AccountStore.swift — kullanıcı bazlı yerel anlık görüntü ("provider:userId" ile anahtarlanmış), oturum kapansa bile XP / rozetler / seviye / kaydedilmiş kelimeler korunur. E-posta hesapları için tuzlanmış SHA-256 (düz metin parola saklanmaz). AccountStore.swift — per-user local snapshot keyed by "provider:userId"; survives sign-out so XP / badges / level / saved-words are restored instantly. Salted SHA-256 for email-account password hashes (no plaintext stored).

StatePersistence.swift — Codable kalıcılık + son-iyi-blob yedeği. Bir sürüm şemayı kırarsa load() yedeğe düşer; tek bir hatalı sürüm kullanıcı ilerlemesini silemez. Savunmacı decoder, yeni alan eklendiğinde eski kayıtları geçersiz kılmaz. StatePersistence.swift — Codable persistence with a prior-good-blob backup. If a release breaks the schema, load() falls back to the backup — a single bad release can't wipe progress. Defensive decoder defaults every field, so adding new keys never invalidates an old save.

Networking — Ağ Networking

OfflineQueue.swift — çevrimdışı öncelikli yazma deseni. Başarısız ağ işlemleri tür bazında kirli bayraklarla işaretlenir (kalıcı operasyon kayıtları değil). NWPathMonitor bağlantı geri geldiğinde tetikler; ön plan olayları yedek tetikleyici olarak çalışır. OfflineQueue.swift — offline-first write pattern. Failed network ops are marked as per-kind dirty flags (not persisted op logs). NWPathMonitor re-fires them when connectivity returns; foreground events double as backup re-drains.

Engagement — Etkileşim Engagement

WeaknessAggregator.swift — kullanıcının WordStat geçmişi üzerinden saf bir fonksiyon → en zayıf 5 kelime + en zayıf 3 CEFR bandı. Bileşik puan = hata oranı × güncellik bozulumu (7 günlük yarı ömür) × CEFR zorluğu × tepelenmiş hata sayısı. Practice Hub'daki "şunları tekrar etmelisin" önerilerini besler. WeaknessAggregator.swift — pure function over the user's WordStat history → top-5 weakest words + top-3 weakest CEFR bands. Composite score = miss-rate × recency-decay (7-day half-life) × CEFR-difficulty × capped error count. Drives the Practice Hub's "you should review these" suggestions.

StreakMilestone.swift — kademeli streak kutlamaları (7 / 30 / 100 / 365 / 1000) tek bir enum içinde modellenmiş: metin, animasyon zamanlaması, arka plan gradient'i, SF Symbol ve ödül ağırlığı hepsi birlikte. Kutlama view'i sade kalıyor; tasarım niyeti domain'de yaşıyor. StreakMilestone.swift — tiered streak celebrations (7 / 30 / 100 / 365 / 1000) modelled as a single enum that owns its copy, animation timing, backdrop gradient, SF Symbol and reward weight. The celebration view stays dumb — all design intent lives in the domain.

Design System — Tasarım Sistemi Design System

FeedbackKit.swift — merkezi haptik. Her çağrı UserDefaults["haptic"]'ı yeniden okur; Ayarlar'daki toggle anında tüm uygulamada etkili olur — cache yok, observer wiring yok. FeedbackKit.swift — centralized haptics. Every call re-reads UserDefaults["haptic"] so the Settings toggle takes effect app-wide immediately — no caching, no observer wiring.

Tokens/Colors.swift + Typography.swift — tasarım-token paleti ve .system(...) üzerine kurulu tip rampası. Uygulama tasarım olarak light mode'a sabitlenmiş (sıcak krem + amber + altın), bu yüzden dark varyantı yok. Numerik rampa için yuvarlatılmış stil. Tokens/Colors.swift + Typography.swift — design-token palette and a type ramp on top of .system(...) so accessibility size scaling stays intact. App is pinned to light mode by design (warm cream + amber + gold) — no dark variants. Rounded design for the numerics ramp.

PrimaryButton.swift — yeniden kullanılabilir CTA buton. Dört görsel stil, gömülü basılma ölçeği, FeedbackKit üzerinden dokunma haptiği. PrimaryButton.swift — reusable CTA button. Four visual styles, built-in pressed scale, haptic-on-tap through FeedbackKit.

Burada olmayan ve nedeni What's NOT in here, and why

  • Auth + Supabase servisleri — gerçek proje URL'i ve anon key'i taşırlar. Her ikisi de uygulama hedefinde gitignore'ludur. Auth + Supabase services — they carry the real project URL and anon key. Both are gitignored in the app target.
  • StoreKit 2 + abonelik mantığı — satın alma / geri yükleme / appAccountToken bağlama / sunucu doğrulama akışı özel repo'da kalır. StoreKit 2 + subscription logic — purchase / restore / appAccountToken binding / server-verification flow lives in the private repo.
  • Apple Server Notifications webhook — Apple'ın JWS imzasını kriptografik olarak doğrular; public yayınlamak uygun değil. Apple Server Notifications webhook — cryptographically verifies Apple's JWS signature; not for public consumption.
  • Ders / sınav / kitap içeriği — CEFR sözlüğü, gramer modülleri, ders bölümleri, seviye geçiş sınavları, uygulama içi kitaplar. Bunlar ürünün kendisi, çatı değil. Lesson / exam / book content — CEFR vocabulary, grammar primers, lesson chapters, level-transition exams, in-app books. These are the actual product, not the framework.
  • AI tutor komut grafikleri ve senaryo kataloğu — her senaryo dikkatle ayarlanmış birkaç yüz token; seviye sınavı puanlama komutları da öyle. AI tutor prompt graphs and scenario catalog — each scenario is several hundred carefully tuned tokens; ditto for the level-exam scoring prompts.
